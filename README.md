# Nordra Studio — Premium Home

Versión refinada del starter de `nordrastudio.mx`, inspirada en la dirección visual aprobada:
- estética oscura premium
- auroras
- montañas
- acentos cyan / azul / violeta
- dark/light mode
- Home orientado a conversión

## Stack
- React
- Vite
- TypeScript
- Tailwind CSS
- Lucide React

## Ejecutar
```bash
npm install
npm run dev
```

## Secciones incluidas
- Header
- Hero
- Beneficios
- Servicios
- Portafolio
- CTA final
- Footer
